Figma を使いこなそう

Figma は Web や アプリケーションなどの画面設計や UI の制作に最大に効果を発揮するように作られたアプリケーションです。

それらの画面がどのような理屈で動いているか、理解することでより目的にマッチした Figma のデザインを作ることができます。

Web デザインの特徴

  • 画面サイズが変動する

    Web サイトを表示する領域は端末や環境によって絶えず変動し、いかなるケースにおいても情報を正しく表示する必要があります。

  • 内容量が変化する

    先の画面幅に関連する内容ですが、文章の折り返しなどが閲覧する環境で変化するため、その変化に合わせてデザインが対応できるように作る必要があります。

  • パーツの共有がある

    例を挙げるとリンクやお問い合わせの UI としてボタンを配置することがあります。 その場合、同じような部品でページごとに差異があるといけないので共通の部品として共有します。

デザインをプロジェクト資産に

Figma はいままでデザイナーの中に閉じられていたデザインを、プロジェクトにかかわるすべての人で共有することを可能にしたツールです。

企画は企画、デザインはデザイン、コードはコードと、分かれていたすべてを統合し、それぞれの役職の垣根を超えた相互理解を促し、デザインを通じてプロジェクトの成果物を良くしていくことが期待できます。

そのためには Figma に用意された機能を正しく利用し、制作するデザインの特徴を理解した上で、一貫して使える資産としてデザインを作っておくことが求められます。
